# Cyber Habitat：安卓桌宠与聊天伴侣开发路线

更新：2026-11-17。此文档是当前产品方向；README 里早期的自治世界和 QQ 路线保留为历史记录。手机尺寸浏览器原型已实现并经过本机检查，安卓原生 App、APK 和系统悬浮窗尚未实现，不能把原型当成已验收的安卓应用。

## 目标与优先级

首版要让 Mori 在手机上以有生命感的桌宠形象出现，并让聊天像与同一个有记忆、有情绪、有分寸的人相处。用户明确表示：平时不自行开展世界活动也可以。优先级依次是：角色的表达与记忆、可触摸的桌宠、好看的主界面、稳定的手机体验。后台自治、赛博世界扩展、QQ、DSH 和多居民留作后续可选能力。

“鲜活”需要由可观察的细节构成：说话方式稳定但不套模板；能准确记住用户说过的重要事，并知道自己不知道什么；会根据上下文换表情、姿势和语气；用户不理她时也能安静待着，不用重复播报“在闲逛”；聊天时有自然的听、想、回应过程。动画不能声称发生了数据库里没有的事件。主动打扰、通知和模型调用必须可关闭、可限额。

## 产品形态

1. **安卓主界面**：屏幕中心是 Mori；对话在下方自然展开；状态和设置收在次级页面。首页只显示她现在的表情/姿势、一句有意义的状态和最近真正发生的互动。避免把“推进一天”、调 API、数值面板放到主视觉中心。
2. **悬浮桌宠**：在用户主动开启并授予系统“显示在其他应用上层”权限后，可以拖动、轻触互动，点击进入聊天。关闭悬浮后主界面仍能使用。悬浮窗的实现须符合 Android `TYPE_APPLICATION_OVERLAY` 权限规则；不要请求无关的无障碍或设备控制权限。
3. **同一个 Mori**：主界面、悬浮窗、聊天和记忆使用同一身份与状态。视觉层根据明确的状态契约选择动作，如待机、注意到用户、聆听、思考、说话、开心、困倦、被拖动；网络或模型故障有安静的降级表现。用户可关动画或减少动态效果。
4. **聊天**：保留现有 DeepSeek 后端和 SQLite 对话存储作为起点。下一阶段补稳定的人格资料、准确的长期记忆提取/检索、最近对话衔接、重复回答抑制、失败恢复和明确的模型费用上限。对话应能围绕共同经历延续，也能坦白不确定。
5. **美术与界面**：先做布局、色彩、字体、层次和动效规范，再接入有权使用的美术。角色表情、背景与聊天气泡形成统一风格；窄屏和深浅环境都要可读。素材先用原创或明确许可的占位，最终替换后做真机视觉检查。

## 实施顺序与验收

### 已完成的本地前置原型

`src/cyber_habitat/habitat.html` 现在以 Mori、原创 SVG 形象和聊天为首页；真实居民状态及最后一次回答驱动内容，轻触、输入、发送会触发招呼、聆听、思考、说话的视觉反馈。旧意图明确标作“上次想做”，默认不会为了动画调用模型或制造世界事件。2026-11-17 在 390×844 浏览器视口检查了布局；用临时 SQLite 数据库及假模型从页面发消息，看到回答并在刷新后保留。本机缺 Android SDK、Gradle 和已连接设备；因此此项只证明移动网页原型，不证明安卓安装或悬浮体验。

### 1. 研究与设计

阅读参考仓库的 Android 悬浮窗、动画驱动、权限流程、资源加载和构建脚本，形成文件级复用审计。画出主界面和悬浮态的手机尺寸草图，确定 Mori 的视觉状态表及触发条件。验收：每个动作都能追到真实输入或状态，素材清单不含许可不明的文件。

### 2. 安卓原型

建立独立 Android 客户端，先完成主界面、聊天、角色待机/聆听/说话三态，再加可开关的悬浮窗和拖动。复用现有服务 API；客户端不保存服务器的 DeepSeek 密钥。验收：在真安卓手机上安装 APK，打开、聊天、切回别的 App 后仍可看到已授权的桌宠，关闭权限后可正常使用主界面。

### 3. 角色质量

让 Mori 能跨重启记住值得记的事，减少相邻回答复述，表情与回答和情绪一致，互动不过度打扰。把用户示例对话做成评审场景，人工检查“像不像同一个人”，同时核对记忆事实和实际费用。无需靠每隔几分钟强制安排世界动作制造存在感。

### 4. 安全连接与发布准备

为手机到 Linux 服务设计账号鉴权、HTTPS、设备会话和退出/撤销；确认数据库备份恢复、密钥存放和费用控制。当前 `127.0.0.1:8765` 服务无登录保护，不可直接公开。完成后再做手机与服务器的真实同步验收。发布前清点第三方代码及素材许可，打包可复现的 APK。

## 现有代码可保留的部分

当前 Python 服务、DeepSeek 接口、SQLite 事件与对话存储、规则审核都可以作为后端基础。`habitat.html` 是开发演示页，不代表最终 UI。自主活动调度保留为可选实验能力，首版默认关闭。QQ/NapCat 保留在隔离的可选配置中，不占当前开发主线。

## 未决定事项

- 悬浮宠物在锁屏、后台省电、横屏与游戏中的表现，以及用户希望的主动提醒频率。
- 是否以后提供 Windows 桌宠；当前首版按安卓手机推进。
